# Nook — Hai thứ tiếng

App nói **tiếng Việt** và **tiếng Anh**. Không có câu nào viết thẳng trong màn
hình; ESLint chặn, tsc chặn, và cả hai đều chặn *trước khi* code chạy.

---

## 1 · Thêm một câu chữ — ba bước

```ts
// 1. src/i18n/locales/vi.ts  ← luôn bắt đầu ở đây
feed: {
  emptyTitle: 'Hết rồi. Chụp gì đó đi.',
  window: 'Chỉ hiện 48 giờ gần nhất.',
  saved: 'Đã lưu về máy',            // ← câu mới
},
```

Lưu file. **tsc lập tức báo đỏ ở `en.ts`** vì thiếu khoá.

```ts
// 2. src/i18n/locales/en.ts
saved: 'Saved to your phone',
```

```tsx
// 3. Trong màn hình
const t = useT();
<Txt>{t('feed.saved')}</Txt>
```

Xong. Không có bước đăng ký, không có tệp JSON nào phải nhớ cập nhật.

## 2 · Bốn thứ tsc bắt được ngay trong editor

| Viết sai | tsc nói gì |
|---|---|
| `t('feed.savedd')` | `Argument of type '"feed.savedd"' is not assignable to parameter of type 'Key'` |
| Thêm khoá vào `vi.ts`, quên `en.ts` | `Property 'saved' is missing … but required in type 'Mirror<…>'` |
| `t('verify.resendIn')` — câu có `{seconds}` mà không truyền | `Expected 2 arguments, but got 1` |
| `t('common.back', { seconds: 1 })` — câu không có chỗ trống mà lại truyền | `Argument of type '{ seconds: number }' is not assignable to parameter of type 'undefined'` |

Cách này hoạt động được là nhờ `vi.ts` khai `as const`: TypeScript giữ nguyên
**từng chữ** của câu, nên nó đọc được `{seconds}` nằm trong đó. Cơ chế đầy đủ ở
`src/i18n/types.ts`.

Thứ tsc **không** bắt được: bản dịch tự chế thêm một chỗ trống bản gốc không có
(`{who}` bên tiếng Anh trong khi tiếng Việt viết `{name}`). Chỗ đó có lưới
riêng — `checkTranslations()` chạy lúc `__DEV__`, in cảnh báo ra console.

## 3 · Số nhiều

```ts
// vi.ts — tiếng Việt KHÔNG đổi dạng theo số, chỉ khai `other`
minutesAgo: { other: '{count} phút trước' },

// en.ts — tiếng Anh có hai dạng
minutesAgo: { one: '{count} minute ago', other: '{count} minutes ago' },
```

```tsx
t('feed.minutesAgo', { count: 1 })   // vi: "1 phút trước"  · en: "1 minute ago"
t('feed.minutesAgo', { count: 5 })   // vi: "5 phút trước"  · en: "5 minutes ago"
```

Câu số nhiều **luôn** đòi `count`, kể cả khi câu không in con số ra:

```ts
// en.ts
waitingTitle: { one: 'One more spot to fill', other: '{count} more spots to fill' },
```

**Không dùng `Intl.PluralRules`** — Hermes không có nó (đã đo, xem
`06-libraries.md` mục 6). Luật hai ngôn ngữ nằm gọn trong `src/i18n/plural.ts`.

## 4 · Ngoài React

`useT()` là hook, không gọi được trong `*Api.ts` hay trong một hàm tiện ích.
Chỗ đó dùng `translate()`:

```ts
import { translate } from '@i18n';

return { ok: false, message: translate('verify.wrongCode') };
```

Cùng bộ chữ, cùng ngôn ngữ đang chọn, chỉ khác là **không theo dõi thay đổi** —
nên đừng giữ lại kết quả trong một biến sống lâu.

## 5 · Số, ngày, "3 phút trước"

```tsx
const n   = useNumber();   n(1234567)                          // vi: 1.234.567
const d   = useDate();     d(new Date(), { day: 'numeric', month: 'long' })
const ago = useAgo();      ago(new Date(moment.at))            // "3 phút trước"
```

`Intl.NumberFormat` và `Intl.DateTimeFormat` **có** trong Hermes và ra đúng
định dạng Việt Nam. Cả hai đều được nhớ lại theo ngôn ngữ: dựng một
`Intl.NumberFormat` tốn khoảng 1ms, mà trong danh sách cuộn thì đó là 1ms nhân
số ô nhân mỗi lần vẽ.

`useAgo` **không** dùng `Intl.RelativeTimeFormat` (Hermes không có) — nó tự
tính rồi tra kho chữ.

## 6 · Cây thư mục

```
src/i18n/
├── index.ts        CỬA DUY NHẤT. Mọi nơi import từ '@i18n'
├── types.ts        suy khoá + tham số từ vi.ts. Chỗ khó nhất, đọc kỹ nếu định sửa
├── core.ts         làm phẳng bộ chữ, tra khoá, điền chỗ trống
├── store.ts        ngôn ngữ đang dùng (Zustand) + nhớ xuống đĩa
├── plural.ts       chọn dạng số nhiều
├── format.ts       số / ngày / khoảng thời gian
└── locales/
    ├── vi.ts       NGUỒN CHUẨN — mọi khoá sinh ra ở đây trước
    ├── en.ts       phải khớp từng khoá với vi.ts
    └── index.ts    danh sách ngôn ngữ, tên hiển thị
```

Không ai import file con. `import { useT } from '@i18n'` — hết.

## 7 · Vì sao `t` nằm trong kho trạng thái

Component đọc bằng selector `useI18n((s) => s.t)`. Chừng nào ngôn ngữ chưa đổi
thì `t` vẫn đúng một tham chiếu cũ → Zustand thấy không đổi → **không vẽ lại gì
cả**. Đổi ngôn ngữ thì `t` thành tham chiếu mới → mọi màn đang mở vẽ lại đúng
một lần.

Đó là con số tối thiểu có thể đạt được, và là lý do không dùng React Context:
Context bắt mọi thứ bên dưới vẽ lại mỗi lần provider vẽ lại.

Vì `t` đứng yên nên nó đặt được vào mảng phụ thuộc của `useCallback`/`useMemo`
mà không gây vẽ lại thừa — xem `renderItem` trong `FeedScreen.tsx`.

## 8 · Ngôn ngữ nào được chọn lúc mở app

1. Người dùng đã tự chọn lần trước → theo lựa chọn đó (nhớ trong AsyncStorage).
2. Chưa chọn bao giờ → theo **ngôn ngữ máy** (`expo-localization`).
3. Ngôn ngữ máy không phải vi/en → **tiếng Anh**.

Màn chờ (splash) được giữ tới khi đọc xong lựa chọn cũ — `useI18nReady()` trong
`app/_layout.tsx`. Thả sớm thì người dùng thấy màn đầu bằng sai ngôn ngữ rồi
đổi, khoảng 30ms, nhưng là 30ms đầu tiên họ nhìn thấy.

Đổi ngôn ngữ: **Cài đặt** (bánh răng ở màn Camera).

## 9 · Luật viết chữ

Áp cho **cả hai** thứ tiếng:

- Ba từ cấm: *điểm*, *hạng*, *nhiệm vụ* — tiếng Anh: *points*, *rank*,
  *quest/mission*. Đây là luật sản phẩm, xem `../../.docs/01-product-system.md`.
- Không chữ kỹ thuật: *OTP*, *xác thực*, *hợp lệ*, *token*, *phiên* —
  *verify*, *valid*, *session*.
- Xưng "mình", gọi người dùng là "bạn". Không "quý khách", không "người dùng".
- Câu lỗi phải nói **được phải làm gì**, không chỉ nói cái gì hỏng.
- Câu tiếng Anh dài hơn câu tiếng Việt cùng nghĩa khoảng 15–20%. Chỗ nào chật
  (nhãn nút, pill) thì **viết ngắn lại**, đừng dịch sát rồi để nó tràn.

## 10 · Lưới ESLint

Ba luật trong `eslint.config.js` chặn chữ tiếng Việt viết thẳng vào code:

| Dạng | Ví dụ bị chặn |
|---|---|
| Chữ trong JSX | `<Txt>Xin chào bạn</Txt>` |
| Chuỗi | `const msg = 'Bạn có 3 người bạn'` |
| Chuỗi có `${}` | `` `Còn ${n} chỗ trống` `` |

Hai chỗ được miễn: `src/i18n/**` (chính là kho chữ) và `src/mocks/**` (tên
người, caption mẫu — sẽ xoá khi có server).

**`src/components/` cũng bị chặn**, và đó là chủ đích: component không biết kho
chữ tồn tại. Nhãn trợ năng nhận qua props (`<Rings label={…}>`,
`<CodeInput label={…}>`), người gọi mới là người dịch. Nhờ vậy component xem
trước được mà không cần dựng cả app.

Lưới chỉ bắt ký tự **có dấu**. `'Bao nhieu'` lọt — chấp nhận được: nó hiếm, và
lưới quá chặt thì người ta tắt luật đi, lúc đó mất cả lưới.
